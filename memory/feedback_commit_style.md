---
name: Commit message style
description: Format to follow for all git commits in this project
type: feedback
---

Always use the project's established one-line format: `English title / 日本語タイトル`

No body, no Co-Authored-By footer.

Examples from git log:
- `Externalize question sets into JSON / 問題セットをJSONへ外出し`
- `Improve user-facing README on main / mainのREADMEを利用者向けに拡充`
- `Fix clippy default derive warning / clippyのDefault derive警告を修正`

**Why:** The repo's commit history consistently uses this bilingual one-liner format.
**How to apply:** Every commit in this repo, no exceptions.
